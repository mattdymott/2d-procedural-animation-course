A course

2D Procedural Animation with Unity DOTS

Rain World-style creatures — soft, bendy bodies that move believably through any space — built from first principles: verlet chains, muscles, analytic and iterative IK, gait, second-order "juice," batching at ECS scale, and a reusable package API. Eight lessons, each with an interactive simulation, a challenge, and a quiz.

About

Written for a reader already fluent in Unity DOTS (ISystem, Burst, jobs, buffers) — the lessons teach the animation techniques, not ECS plumbing. Math is presented as intuition and ready-to-adapt recipes rather than derivations.
