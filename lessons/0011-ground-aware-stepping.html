Ground-Aware Stepping: Promises to Terrain

Lesson 4 taught a foot to promise a point in empty space. Lesson 10 taught the body not to enter terrain. Now connect them: choose a safe point on terrain before the swing begins. The lizard stops pretending the world is a flat line.

The one rule: query once, then commit

A raycast or tile query is a sensor, not a foot controller. At the instant a planted foot decides to swing, sample terrain under its predicted home point. Filter that hit. If it is safe, store its point as SwingTo; after landing it becomes Plant. Do not keep raycasting under a planted foot. A moving query result turns a planted promise into skating.

Recipe · choose a foothold at swing start
probe = home + bodyVelocity * lead
hit   = groundQuery.CastDown(probe)

if (hit.exists
    && dot(hit.normal, up) >= minSupport
    && IsWithinIkReach(hip, hit.point)
    && IsForwardEnough(hit.point, home, bodyVelocity))
    beginSwing(from: leg.Plant, to: hit.point)
else
    keepPlantOrUseSafeFallback()

There are two important ownership boundaries. The terrain adapter only reports a hit, normal, and material. Gait decides whether that hit is a foothold. IK still owns reachability; contact constraints still own the final legal foot after it lands. No query gets to rewrite a planted foot by itself.

What if nothing is valid?

Fail safely. Keep the existing plant for one more tick, shorten the proposed step, or choose an explicit recovery behaviour. A bad hit is worse than no hit: teleporting to it creates a broken IK promise, then asks the solver to hide the error. This is the same discipline as L10 contact — preserve legality first.

DOTS mapping

Give gait a narrow query seam such as IGroundQuery.TryFindFoothold or a gathered buffer of terrain samples. That keeps the L4 state machine testable and lets a tilemap, Unity Physics world, or custom SDF implement discovery. The hot gait loop consumes only compact hit data.

public struct GroundHit
{ public bool Exists; public float2 Point, Normal; public byte Surface; }

// At transition Planted → Swinging only:
GroundHit hit = groundQuery.CastDown(probe);
if (AcceptFoothold(hit, hip, settings, bodyVelocity)) {
    leg.SwingFrom = leg.Plant;
    leg.SwingTo   = hit.Point;       // commit once
    leg.State     = FootState.Swinging;
}
// While Planted: leg.Plant stays unchanged; do not overwrite it from a query.

Unity’s raycast APIs take an origin, direction, maximum distance, and collision filtering, and return hit information for the closest collider. The exact adapter is project-specific; the gait contract above is not. [Unity Raycast documentation]
