Reserve One Top-Down Foothold

A candidate is not a live sensor reading. At swing start, gait chooses one legal world point and carries that promise to landing—even if the creature turns and another point looks better a moment later.

Try the reservation experiment

Query the three points, reserve either legal shelf, then change heading during the purple swing. The gold home may move; the purple candidate should not. Finally land it. Repeat with the “query every tick” bug to see the target chase the body.

Start by querying candidates. Nothing may change the committed pale plant yet.

if (foot.Phase == Planted && gait.AllowsSwing(foot))
{
    foot.CandidateWorldPoint = QueryBestLegalFoothold(foot, world);
    foot.Phase = Swing;

if (foot.Phase == Swing && Reached(foot.CandidateWorldPoint))
{
    foot.PlantedWorldPoint = foot.CandidateWorldPoint;
    foot.Phase = Planted;
}

Keep the query result and the plant in separate fields. A new terrain query belongs at a new transition, never in the planted or swinging update loop. If the candidate becomes unsafe mid-swing, make that an explicit recovery outcome; do not silently retarget it every frame.
