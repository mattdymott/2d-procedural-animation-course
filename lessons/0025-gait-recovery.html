Gait Recovery: When No Foot May Go There

A careful crawler eventually asks its permitted leg to step somewhere impossible. That is not a bug in need of a hidden correction—it is the moment to hold, request a safe change of intent, and keep every existing promise honest.

Failure is a gait state

Recipe · hold first, recover explicitly
candidate = planarQuery.FindAtSwingStart(permittedLeg);

if (!IsLegal(candidate, permittedLeg))
{
    gait.Recovery = RecoveryState.HoldingForFoothold;
    gait.CursorOrGroupStaysUnchanged();

    recoveryRequest = new RecoveryRequest
    {
        SlowDown = true,
        PreferredTurn = FindSafeDirection(),
    };
    return; // Plant and SwingTo remain unchanged
}

BeginSwing(permittedLeg, candidate.Point);

The recovery request is a semantic handoff to locomotion: slow, turn, backtrack, or enter an authored escape. It is not a command to invent a target. Once intent changes, the same gait policy tries again at a real swing transition.

DOTS mapping

Keep recovery as one field in the gait module and one semantic output for locomotion. It does not require a second foot controller or a renderer-to-gameplay callback.

public enum GaitRecovery : byte { None, HoldingForFoothold, Escaping }

public struct GaitRecoveryRequest : IComponentData
{
    public byte SlowDown;
    public float2 PreferredTurn;
}

// Locomotion reads the request; gait retains Plant and policy state.
