Wave Gait: One Foot at a Time

Tripods make a quick, confident insect. A wave gait makes a slow, deliberate crawler: one ordered leg moves while the other five remain planted.

Replace groups with a cursor

Author a loop through the six legs. The cursor points to the only leg allowed to ask for a swing. When that leg lands, advance once. This makes support simple and lets a cautious creature negotiate tight spaces without a broad, simultaneous step.

Recipe · cursor-gated stepping
int legIndex = gait.WaveOrder[gait.Cursor];
ref GaitLeg leg = ref legs[legIndex];

if (leg.State == Planted && Stress(leg) > settings.Comfort)
{
    candidate = planarQuery.FindAtSwingStart(leg);
    if (IsLegal(candidate, leg))
        BeginSwing(leg, candidate.Point);
    else
        HoldOrUseRecovery(leg); // cursor does not advance
}

if (leg.State == Planted && leg.JustLanded)
    gait.Cursor = (gait.Cursor + 1) % gait.WaveOrder.Length;

The cursor owns permission, not landing geometry. The current leg still needs its own reachable, walkable, path-clear candidate. If it cannot find one, holding position is clearer than silently skipping ahead to another foot.

Tripod and wave are policies, not different legs

PolicyLegs permitted to swingCharacter
Alternating tripodOne diagonal group while its opposite group plants.Quick, broad, rhythmic.
Wave cursorOne authored leg at a time.Slow, deliberate, stable.
RecoveryExplicitly chosen when policy cannot progress.Contextual, inspectable.

The same GaitLeg state, foothold query seam, IK solver, support relation, and presentation layer serve both policies. Only the internal permission rule changes.

DOTS mapping

Bake a six-entry order into creature configuration and keep a single mutable cursor. The gait module maps the cursor to its existing leg buffer; no system outside gait needs to know whether this creature uses tripod or wave cadence.

public struct WaveGaitState : IComponentData
{
    public byte Cursor;
}

[InternalBufferCapacity(6)]
public struct WaveOrder : IBufferElementData
{
    public byte LegIndex;
}

Where to go deeper

Primary source: David Rosen’s Animation Bootcamp remains the course foundation for small, inspectable rules that make locomotion readable. A wave cursor is deliberately that small: one permission rule added to the existing foot state machine.

Keep the wave gait cheatsheet beside alternating tripods and planar footholds.

Suggested real-world rep: give the L9 creature a six-entry crawl order and turn on a cursor label in Scene view. Put a blocked tile under the current leg’s only candidate. Verify it holds the cursor rather than making a later foot jump ahead.

Ask about choosing tripods versus waves from speed, blending cadence through turns, or a recovery policy for a stuck cursor.
