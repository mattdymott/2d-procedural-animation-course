Turn Anticipation: Tell Before You Turn

A planned direction change can be visible before the legal body actually changes course. Let presentation briefly bank the body away from the upcoming turn; let locomotion and gait carry on with their existing authority.

Intent can inform the picture

Recipe · an opposite render bank
// Locomotion exposes a semantic intent, not a sprite command.
float requestedTurn = steering.RequestedTurnSign;

// Presentation reads it before the resolved heading changes.
float anticipation = -requestedTurn * visual.AnticipationBank;
visual.Bank = UpdateSecondOrder(visual.Bank, anticipation, deltaTime);

// Later, resolved angular velocity drives the normal turn bank.
// No presentation value is written back to heading, targets, or feet.

This is a short visual lie for the eye. It works especially well with a top-down insect because the planted base and the body’s visual lean become two separate, readable layers: one says “still supported,” the other says “about to turn.”

DOTS mapping

Expose requested turn as a semantic locomotion fact. The presentation system reads that fact plus resolved heading, then evolves its own second-order bank. Gait and IK remain unaware that anticipation exists.
