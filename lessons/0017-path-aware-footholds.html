Path-Aware Footholds: Choose Once, Then Commit

A top-down obstacle is not a bad floor normal. It is a reason a planar point is not a legal foot target. Let sensing offer candidates; let gait choose one promise.

Replace “support normal” with a landing policy

Lesson 11 selected a point on terrain by checking whether its normal could support a foot. The top-down equivalent asks a different question: can this leg usefully put its foot there without crossing forbidden space?

Recipe · gather facts, then make one promise
predictedHome = home + bodyVelocity * lead
candidates    = planarQuery.SampleAround(predictedHome)

foreach (candidate in candidates)
{
    if (!candidate.Walkable) continue;          // not inside a blocked region
    if (!candidate.PathClear) continue;         // no wall between swing and target
    if (!WithinIkReach(hip, candidate.Point)) continue;
    if (!MatchesStepPolicy(candidate.Point, predictedHome)) continue;

    BeginSwing(from: leg.Plant, to: candidate.Point);
    return;                                     // one committed target
}

KeepPlantOrChooseRecovery();                    // never invent an impossible promise

A query can be a tile map, a physics overlap, a navigation field, or a signed-distance function. Its implementation is deliberately hidden behind the narrow seam. The gait only consumes compact evidence about possible points.

The playground: choose the foot’s next promise

The body wants to move right. Select the one candidate that is walkable, reachable, forward enough, and connected to the current foot by a clear route. After choosing, the target is fixed until this swing completes.

This is the same ownership discipline as ground-aware stepping. More sensing does not mean more writers. A planted foot is still the state machine’s promise, not a live cursor hovering over navigation data.

DOTS mapping

Have an adapter gather a small buffer of world facts before the solve group. Gait runs only on the Planted → Swinging transition, picks one candidate, and writes the existing swing fields. The buffer can come from any query backend without broadening the gait API.

public struct PlanarFootholdCandidate : IBufferElementData
{
    public float2 Point;
    public byte Walkable;
    public byte PathClear;
    public byte Surface;
}
