Alternating Tripods: A Gait for Six Legs

A quadruped can usually coordinate with a partner guard. A six-legged insect benefits from a stronger rhythm: one diagonal tripod remains planted while the other may move.

Support becomes cadence

Tripod A is front-left, middle-right, rear-left. Tripod B is the opposite diagonal. While A swings, B remains the base; then they exchange. This is a gait policy layered over the top-down support rule, not a replacement for planar target filtering.

Recipe · choose a tripod without weakening promises
bool mayStartA = AllPlanted(tripodB) && Urgency(tripodA) > threshold;
bool mayStartB = AllPlanted(tripodA) && Urgency(tripodB) > threshold;

Tripod chosen = HighestUrgencyAllowedGroup(mayStartA, mayStartB);
foreach (leg in chosen)
{
    candidate = planarQuery.FindAtSwingStart(leg);
    if (IsLegal(candidate, leg))
        BeginSwing(leg, candidate.Point);
    else
        HoldOrUseRecovery(leg);
}

Do not promote “tripod” into a second simulation authority. Gait still owns each leg’s plant, target, and timer; the group only gates which set is permitted to begin.

DOTS mapping

Keep one leg buffer. Add a baked TripodGroup byte per leg and a small gait-phase state. The gait module derives group readiness from existing leg state; it does not need six separate components or a public coordination graph.

public struct InsectLegConfig : IBufferElementData
{
    public byte TripodGroup; // 0 = A, 1 = B
    public float2 LocalHome;
}

bool OpposingGroupIsPlanted(DynamicBuffer legs, byte group);

Where to go deeper

Primary source: David Rosen’s Animation Bootcamp remains the course anchor for using small rules to produce readable locomotion. Treat alternating tripods as one more small, inspectable rule—not a collection of authored poses.

Keep the alternating tripods cheatsheet beside support policy and planar footholds.

Suggested real-world rep: build a six-legged top-down creature with coloured tripod overlays. On a straight walk, show one planted tripod and one swinging tripod. Place a blocked island under one target: the group must hold or recover, never send the planted tripod into swing.

Ask about a slower wave gait, uneven terrain policies, or blending this cadence into a turning behaviour.
