Supported Turning: Never Lift the Last Base

Heading-relative homes make a stationary turn create foot stress. That does not mean every stressed foot should move. Gait needs one more rule: preserve enough planted feet to make the turn read as supported rather than as a sliding sprite.

Stress asks; support permits

Lesson 16 gave a turning foot a reason to step. Lesson 17 made its destination legal. Now decide which stressed foot may take that step. A simple partner guard remains useful, but a top-down creature with four or more legs benefits from checking the plants it would leave behind.

Recipe · choose one eligible swing
foreach (leg in legs)
{
    leg.Urgency = length(leg.Plant - leg.HeadingRelativeHome);

    leg.Eligible =
        leg.State == Planted
        && leg.Urgency > settings.Comfort
        && RemainingPlantedCountWithout(leg) >= settings.MinSupport
        && RetainsSupport(bodyPosition, PlantsWithout(leg));
}

legToMove = HighestUrgencyEligibleLeg(legs);
if (legToMove.exists)
    BeginSwing(legToMove);   // exactly one new commitment this tick
else
    HoldOrUseRecovery();

RetainsSupport can begin as a diagonal-partner rule, a minimum planted count, or a simple “body remains inside the remaining feet” test. Pick the smallest rule that gives your creature a convincing base. The gait owns that policy; neither IK nor rendering should invent it afterward.

The playground: when is a second swing illegal?

For a biped, “the other foot is planted” is usually enough. For a quadruped, begin with an alternating/diagonal pair or a three-foot minimum. Only add geometric support-region tests when your creature’s actual turns expose a problem that the smaller policy cannot express.

DOTS mapping

Keep the policy inside the gait module. A per-creature leg buffer already has the states and plants it needs; the system can gather stress, test prospective remaining plants, and commit one leg without exposing a public “support polygon” component graph.

public struct GaitSupportSettings : IComponentData
{
    public byte MinSupport;
    public float TurnUrgencyBias;
}

// Internal gait helper: receives current leg buffer, returns one index or -1.
int ChooseEligibleLeg(in DynamicBuffer legs, float2 bodyPosition);
