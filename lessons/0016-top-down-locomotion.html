Top-Down Locomotion: The Plane Is Ground

The side-view gait is not fundamentally about down. It is a body moving past feet that have made promises. In top-down, put that promise on a movement plane and rotate each foot’s home with body heading.

Keep the contract; replace the frame

Lesson 4 gave every foot a planted world point, a moving home, a comfort radius, a led target, and a swing. Keep all of it. Retire only the shortcut “home is below a hip on ground Y.”

Recipe · local leg intent becomes a planar home
// Choose XY or XZ once. This creature moves in XY.
float2 forward = math.normalizesafe(bodyVelocity, previousForward);
float2 right   = new float2(-forward.y, forward.x);

float2 offset = leg.LocalHome;     // authored forward/lateral offset
float2 home   = bodyPosition
              + forward * offset.x
              + right   * offset.y;

float stress = math.length(leg.Plant - home);
if (stress > settings.Comfort && PartnerMaySupport(leg))
    BeginSwing(leg, home + bodyVelocity * settings.Lead);

At zero speed, preserve previousForward. When the creature turns, homes rotate even if its centre stays still. A planted foot then gains honest stress and can request a step rather than slide.

DOTS mapping

Bake each leg’s local home, comfort, and lead. Runtime gait owns plants, swing state, and last non-zero heading. Ownership remains: locomotion writes pose/velocity; gait writes targets; IK resolves limbs; presentation adds lift and sorting.

public struct PlanarLegConfig : IBufferElementData
{
    public float2 LocalHome;
    public float Comfort;
    public float Lead;
}

public struct PlanarHeading : IComponentData
{
    public float2 LastForward;
}
