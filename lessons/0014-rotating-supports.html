Rotating Supports: Carry the Contact Point

A planted foot already rides a support by keeping a local point. At liftoff, though, the creature needs the velocity of that point. A turntable’s centre can be still while its rim is moving quickly.

The one move: evaluate velocity where the promise is

Use the same committed world plant that you feed to IK. Its support-point velocity is the support’s linear velocity plus a tangential term from rotation. In 2D, counter-clockwise angular velocity uses the perpendicular vector perp(x, y) = (-y, x).

Recipe · a relative plant on a rotating support
// Planted: unchanged from Lesson 12.
worldPlant = pose.TransformPoint(localPlant);
ik.Target  = worldPlant;

// Liftoff: sample the velocity of THIS material point.
radius        = worldPlant - support.PivotWorld;
pointVelocity = support.LinearVelocity
              + support.AngularVelocityRad * Perp(radius);

// If Lesson 13's belt is present, add its world surface travel too.
carryVelocity = pointVelocity
              + pose.TransformDirection(belt.VelocityLocal);

The support root is not the contact point. On a static turntable, root velocity is zero; a planted rim point still moves tangentially. The point on the opposite side moves equally fast in the opposite direction. This is exactly what Unity’s Rigidbody2D.GetPointVelocity contract accounts for: velocity at a world point includes angular velocity.

DOTS mapping

Snapshot support motion alongside pose data. The hot leg loop needs only a pivot, a linear velocity, an angular velocity in radians per second, and the already-resolved WorldPlant. That makes contact carry a pure float2 calculation.

public struct SupportMotion : IComponentData
{
    public float2 PivotWorld;
    public float2 LinearVelocity;
    public float AngularVelocityRad;
}

static float2 PointVelocity(in SupportMotion motion, float2 worldPoint)
{
    float2 r = worldPoint - motion.PivotWorld;
    return motion.LinearVelocity + motion.AngularVelocityRad * new float2(-r.y, r.x);
}

If your support originates in Unity 2D physics, convert its documented degrees-per-second angularVelocity to radians once at the adapter boundary. The rest of the animation package stays unit-consistent.
