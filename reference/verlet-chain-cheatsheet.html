Verlet Chain Cheatsheet

The two recipes plus tuning table. Taught in Lesson 1; bedrock source is Jakobsen, Advanced Character Physics (GDC 2001).

1 · Integrate (per point, per fixed step)

velocity     = position - prevPosition       // implied velocity
prevPosition = position
position    += velocity * (1 - damping) + acceleration * dt²

State per point: Position, PrevPosition. Nothing else. To spawn a point at rest, set both equal. To launch it, offset PrevPosition backwards along the desired velocity.

2 · Relax (per link, × iterations)

delta = b.position - a.position
dist  = max(length(delta), 1e-6)
corr  = delta * (0.5 * (dist - restLength) / dist)
a.position += corr
b.position -= corr
  • Pin: after each sweep, snap the pinned point back to its target. For unequal masses, split the correction by inverse mass instead of 0.5/0.5 (a pin is just infinite mass).
  • Order: sweeping head→tail each iteration is fine; alternating direction converges slightly faster.

DOTS shape

VerletPoint  : IBufferElementData { float2 Position, PrevPosition }
ChainSettings: IComponentData     { float RestLength; int Iterations; float Damping }
// One entity per creature; one Burst IJobEntity; parallelism ACROSS entities.
// Run inside FixedStepSimulationSystemGroup — dt² and iteration stiffness
// are not framerate-independent otherwise.
