Moving Platform Cheatsheet

Keeping a planted foot true while its support moves, taught in Lesson 12.

The contract

Static terrain plant = world point. Dynamic support plant = support entity + local point. Gait still owns when a foot plants; the support transform owns how that promise moves through world space.

// landing on a support
leg.Support = hit.Entity;
leg.LocalPlant = InverseTransformPoint(hit.Entity, hit.Position);

// every planted tick
leg.WorldTarget = TransformPoint(leg.Support, leg.LocalPlant);
ik.Target = leg.WorldTarget;

// liftoff: clear the relation; the swing uses world-space from/to points

Failure modes

Stored stateResult
Old world point on a moving platformFoot stays behind; visible skating and impossible strain.
Fresh query every planted tickFoot chases sensor noise; the promise is no longer stable.
Support-local pointFoot rides the support exactly until gait chooses liftoff.
