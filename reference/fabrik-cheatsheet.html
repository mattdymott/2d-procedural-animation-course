FABRIK Cheatsheet

n-joint position-based IK. Taught in Lesson 5; source: Aristidou & Lasenby 2011. Inner operation = L1's distance constraint, swept with intent.

The solver

if length(target - root) ≥ Σ boneLengths:
    lay chain straight from root toward target; return   // unreachable: 1 pass

repeat up to maxIters (2 is plenty warm-started):
    p[n-1] = target                                       // BACKWARD: tip → root
    for i = n-2 .. 0:  p[i] = p[i+1] + normalize(p[i]-p[i+1]) * rest[i]
    p[0] = root                                           // FORWARD: root → tip
    for i = 1 .. n-1:  p[i] = p[i-1] + normalize(p[i]-p[i-1]) * rest[i-1]
    if length(p[n-1] - target) < tolerance: break         // early-out

Key facts

FactConsequence
No angles, no matrices — positions on lines onlyTrig-free, Burst-friendly, verlet-native
Warm start = last frame's pose (free with a DynamicBuffer)~1 iteration/frame tracks a moving target sub-pixel
Unreachable detected up frontGraceful strain: point at what you can't have (cf. L3 annulus clamp, L4 red legs)
Solution is a proposal pose, not a commandBlend toward it by grabStrength — the wish⇄promise dial

The grab muscle

sol = fabrik(currentPose, target)
p[i] += (sol[i] - p[i]) * grabStrength      // 0.2 = reaching wish, 1.0 = grabbing promise
// then hard sweeps legalize, as always: muscles propose, constraints dispose

Tuning & failure modes

SymptomCauseFix
Chain loses its droop/character when grabbingFABRIK pose is maximally direct; personality was in the slackLower grabStrength, or bias toward a rest pose between passes, or keep tone muscle running
Tip vibrates near targetTolerance too small vs blend strength fighting gravityTolerance ≈ 0.25–0.5px, or raise grabStrength
Solve cost spikes on cold spawnsCold start needs more iterationsCap iterations anyway — one visually-imperfect frame is invisible
Multiple chains/effectors neededBase algorithm is single chainPaper's multi-effector variant (sub-bases); see project page

DOTS notes

  • Solve into stackalloc Span<float2> — allocation-free; chains are short.
  • Buffer positions are the warm start; MaxIters 2 + early-out is production-honest.
  • Runs inside the same chain job, after muscles, before hard sweeps.
