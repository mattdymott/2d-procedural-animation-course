Ground-Aware Stepping Cheatsheet

Turning an L4 home point into a reliable terrain foothold, taught in Lesson 11.

The contract

Sample terrain at swing start; commit one accepted hit as the target; preserve it while planted. Gait owns the promise. The query supplies candidates, never a live replacement for a planted foot.

Foothold recipe

candidate = GroundQuery.CastDown(home + velocity * lead)
if (candidate.hit
    && dot(candidate.normal, up) >= minSupport
    && IsWithinIkReach(hip, candidate.point)
    && IsForwardEnough(candidate.point, home, velocity))
    beginSwing(from: plant, to: candidate.point)
else
    keepPlantOrUseSafeFallback()

Ownership

StateOwner
Terrain hit, normal, materialGround-query adapter

Failure-safe order

  1. Reject a ceiling, wall, or slope beyond the supported normal.
  2. Reject a hit outside the IK annulus.
  3. Reject a backwards target unless deliberately stepping backwards.
  4. If nothing is valid, retain the old plant or shorten the step — never teleport to a bad hit.
