Two-Bone IK Cheatsheet

Analytic limb solver, position form. Taught in Lesson 3; angle-form derivation in Zucconi's IK in 2D.

The mental model

Knee = intersection of two circles (radius L1 around root, radius L2 around foot). Two intersections exist → bendSign = ±1 picks knee-up or knee-down. Reachable region = annulus [|L1−L2|, L1+L2].

The solver

d    = max(length(target - root), ε)
dir  = (target - root) / d
d    = clamp(d, |L1-L2| + ε, L1 + L2 - ε)     // annulus clamp
foot = root + dir * d
cosA = (L1² + d² - L2²) / (2·L1·d)             // law of cosines
a    = acos(clamp(cosA, -1, 1)) * bendSign
knee = root + rotate(dir, a) * L1               // rotate = 2D rotation of dir by a

bendSign rules of thumb

  • Per-limb constant: legs knee-backward (or forward — pick your creature's silhouette), arms elbow-opposite.
  • Never flip per-frame from a heuristic — the knee visibly snaps through the limb. If a flip is unavoidable, blend the knee position over a few ticks or hide it during a step.
  • The unused solution is the mirror of the used one across the root→foot line.

Combining with verlet bodies (wishes + promises)

tick order:
  1. verlet body integrates + muscles fire        (L1, L2 lessons)
  2. gait/AI writes limb.Target, body writes limb.Root
  3. IK solves knee + foot analytically
  4. knee/foot written into verlet buffer as strength-1 pins
  5. hard constraint sweeps legalize the whole creature

Soft parts flow (spine, tail); planted parts promise (feet, grips). Rain World's creatures are this exact marriage.

DOTS notes

  • Pure static function, no state, no iteration — perfect Burst candidate; use math.sincos.
  • Constant cost per call → thousands of limbs, flat profile, deterministic.
  • Data flow one direction per tick: body → targets → solve → pins. No mid-job lookups needed.
