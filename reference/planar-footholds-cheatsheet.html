Planar Footholds Cheatsheet

Choosing a legal top-down foot target, taught in Lesson 17.

The contract

At swing start, gather planar candidates; accept one; commit it as SwingTo; never make a planted foot follow refreshed sensing.

Acceptance order

for each candidate around predictedHome:
    reject if !candidate.Walkable
    reject if !candidate.PathClear
    reject if !WithinIkReach(hip, candidate.Point)
    reject if !MatchesMovementPolicy(candidate.Point)

Failure-safe policy

No valid candidate is useful information. Retain the old plant briefly, shorten the intended step, turn, or enter an authored recovery. Never teleport to the nearest blocked point and ask IK or rendering to disguise it.
