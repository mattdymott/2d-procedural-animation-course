Gait Cadence Switching Cheatsheet

Choosing and safely changing between wave and tripod cadence, taught in Lesson 24.

The contract

Intent requests a cadence. Gait applies it only at a safe synchronization point. Existing plants and active swings are never reset.

requested = desiredSpeed >= tripodEnterSpeed ? Tripod : Wave

if (requested != active)
    pending = requested

if (pending != active && NoLegIsSwinging(legs)):
    active = pending
    InitializePolicyCursorFromCurrentPlants()

Use hysteresis

ThresholdPurpose
Tripod enter speedSpeed above which the creature requests a faster cadence.
Tripod exit speedLower speed below which it requests the wave gait.
Gap between themPrevents cadence flicker near one boundary.

Safety rules

  • Finish an active swing before changing policies.
  • Preserve every existing plant and support relation.
  • Use a pending request rather than resetting gait phase on speed change.
  • Let each newly permitted leg still filter its own candidate.
