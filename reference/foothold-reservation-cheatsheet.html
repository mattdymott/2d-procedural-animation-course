Foothold Reservation Cheatsheet

The query-once, commit-on-landing contract from Lesson 30.

Four states, two persistent points

PhaseQuery?CandidatePlant
PlantedNoNone or previous diagnostic valuePersistent world point
SelectingYes, onceChoose one legal world pointUnchanged

Minimal transition recipe

candidate = QueryBestLegalFoothold(foot, world) // one transition
foot.Phase = Swing

if (Reached(candidate))
{
    plant = candidate                              // one transition
    foot.Phase = Planted
}
