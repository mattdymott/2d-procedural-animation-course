Glossary

Course nomenclature. Every lesson uses these terms in exactly these senses. Terms are added as lessons introduce them.

TermMeaningIntroduced
Verlet integration Advancing motion by storing position + previous position; velocity is implied by their difference, never stored. L1
Implied velocity position − prevPosition. Changes coherently whenever a point is shoved, which is what makes verlet constraint-friendly. L1
Distance constraint The rule that two points stay restLength apart, enforced by moving both toward legality. L1
Relaxation Repeatedly sweeping all constraints, each pass shrinking the remaining error (a Gauss–Seidel-style solve). Iteration count ≈ stiffness. L1
Chain Points linked in sequence by distance constraints; the atomic body part (tail, spine, tentacle, rope). L1
Pin A point forced to a target position after each relaxation sweep; equivalently, an infinite-mass point. L1
Stretch error Average |actual − rest| / rest across links; how illegal a chain currently is. The playground readout. L1
Muscle A constraint corrected only fractionally toward a desired state ("a rule broken on purpose, weakly"). Strength = the fraction. L2
Goal muscle / weak pin Partial lerp of a point toward a target each tick; strength 1 is a pin, strength ≪ 1 is intent. L2
Rhythm muscle / traveling wave Perpendicular sinusoidal shoves with phase lag per link (−i·k), producing undulation that moves along the body. L2
Tone / posture spring Skip-one (i−1 ↔ i+1) distance constraint at rest 2·restLength, partially corrected; resists bending, sets stiffness of character. L2
Envelope Per-link amplitude scaling that assigns a muscle its territory on the body, preventing two muscles fighting over the same points. L2
Muscles propose, constraints dispose Tick order: integrate → fire muscles once (partial) → hard sweeps + pins last, so no muscle setting can break the body. L2
Inverse kinematics (IK) Computing joint positions/angles from a desired end-effector position — a promise the foot is exactly there, versus a muscle's wish. L3
End effector The terminal point of a limb chain that the IK target refers to — the foot, hand, or tongue tip. L3
Annulus / dead disk Reachable region of a two-bone limb: the ring [|L1−L2|, L1+L2]. Unequal bones leave an unreachable disk around the root. L3
bendSign ±1 selecting which of the two circle-intersection knees to use; a stable per-limb modelling choice, not a per-frame optimization. L3
Wishes vs promises Course shorthand: muscles make wishes (partial corrections, physics votes); IK makes promises (exact placement this tick). Feet need promises. L3
Gait The visible walking pattern; in this course an emergent consequence of stepping rules, never authored directly. L4
Home / comfort zone A foot's neutral footprint under its hip (moves with the body) and the stress radius around it beyond which the foot asks to step. L4
Stress Distance from a planted foot to its home point; the quantity the step trigger watches. L4
Partner guard The rule that a foot may only swing while its partner is planted; the entire coordination system, from which alternation emerges. L4
Step lead Planting ahead of home by bodyVelocity·lead seconds so the foot lands unstressed; the anti-limping dial (Little Polygon: "step extrapolation"). L4
Event-driven vs phase-driven gait Stepping triggered by circumstances (stress) vs by a per-leg metronome (sine phase, π offset). Reactive/animal vs regular/confident. L4
FABRIK Forward And Backward Reaching IK: n-joint solver whose passes are directional length-fixing sweeps from alternately teleported endpoints. Position-based, trig-free. L5
Backward / forward pass Teleport tip onto target and sweep toward root; then teleport root onto anchor and sweep toward tip. One round trip = one iteration. L5
Warm start Solving each frame from last frame's pose. Targets barely move per frame, so ~1 iteration tracks sub-pixel — the real cost of FABRIK in games. L5
Grab muscle / grabStrength Blending the chain toward the FABRIK solution pose by a 0..1 strength — one dial spanning the wish⇄promise spectrum for the whole chain. L5
Second-order dynamics A spring-damper filter with a velocity state, mapping an input value to a juiced output that can overshoot, ring, settle, or anticipate. Droppable on any value. L6
f / ζ / r The three intuitive knobs: frequency (response speed), damping (settle behaviour), response (launch character — negative = anticipation). L6
Anticipation Winding up backward before moving toward a target; here it emerges from a negative r feeding the k3·xd term with reversed sign. L6
Follow-through / overshoot Output passing the target then settling back; produced by underdamping (ζ < 1). The filter's velocity also drives squash-and-stretch for free. L6
Stability clamp (k2s) max(k2, T²/2 + T·k1/2, T·k1) — floors the k2 divisor so a fast f at a coarse timestep can't blow up. Never skip it. L6
Frame budget per-creature cost × count ≤ your slice of the 16.6ms frame. The lens for all scale decisions. L7
Parallelize across, not within Chains are sequential internally, so the parallelism is the many independent creatures — one IJobEntity iteration each. L7
Structural change Adding/removing components or spawning moves archetypes and forces a sync point that stalls workers; avoided via enableable flags + pooling. L7
Enableable component An IEnableableComponent toggled in place with no archetype change or sync point — the cheap way to represent dead/swinging/grab-active/LOD-tier state. L7
InternalBufferCapacity Inline buffer size in the chunk; sized to the typical chain, points stay cache-local. Overflow spills to heap and wastes the inline slot. L7
Simulation LOD Near creatures full-fidelity every frame; far creatures fewer iterations updated every Nth frame (round-robined by index). The orders-of-magnitude scale lever. L7
Composition is the API A creature is whichever small components an entity carries, not a God-component or class. Mix VerletChain/Muscles/Limb2Bone/Gait/... freely. L8
Deep module A simple interface hiding a powerful implementation (Ousterhout). Gait's four floats over a whole state machine. The cost of a module is its interface. L8
Config baked / state separate Authoring → Baker → immutable Config component; mutable runtime state (Y, foot phase) in separate components. Data never tangles with behaviour. L8
Two layers + escape hatch Pure static Burst primitives (Ik.Solve2Bone, Fabrik.Solve, SecondOrder.Step) under the authoring components. Deep facade for the common case; primitives for going off-road. L8
Progressive disclosure Sensible defaults make the common case zero-config; advanced knobs exist but never block the beginner. The component surface is the stable contract. L8
