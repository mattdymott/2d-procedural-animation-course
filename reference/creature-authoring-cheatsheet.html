The contract

Save the recipe. Derive the preview. Simulate the history.

Safe edit loop

serializedObject.Update();
DrawPreview(blueprint);                    // pure, derived
EditSerializedBlueprintProperties();       // inspector / handles
serializedObject.ApplyModifiedProperties();// writes targets + Undo

// Baker copies blueprint → immutable config.
// Runtime creates and owns state separately.

Failure modes

ShortcutResult
