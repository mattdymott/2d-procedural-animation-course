Wave Gait Cheatsheet

A slow, stable six-legged crawl, taught in Lesson 23.

The policy

Keep a fixed authored leg order. Only the current cursor leg may begin a swing; do not advance the cursor until that leg has landed.

order = [front-left, middle-right, rear-left,
         rear-right, middle-left, front-right]

leg = order[cursor]
if (leg is planted && Stress(leg) > comfort && HasLegalCandidate(leg)):
    BeginSwing(leg)

if (leg lands):
    cursor = (cursor + 1) % order.Length

Why it works

PropertyResult
One swing legFive planted legs give a large, calm visual base.
Cursor stays on failureAn invalid target never silently changes the gait order.
Each leg filters candidatesOrdered cadence does not create impossible promises.
Explicit recoveryA blocked leg can hold, turn, or use authored escape behaviour.
