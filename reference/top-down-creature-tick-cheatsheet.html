Top-Down Creature Tick Cheatsheet

The complete top-down hand-off, taught in Lesson 20.

The invariant

Move the body on a plane. Let gait commit foot promises. Let IK and constraints make those promises legal. Let presentation make them visible.

One fixed tick

StageWritesMust not write
1. IntentDesired planar velocityFeet or joints
2. Planar locomotionBody position, heading, local homesFoot plants
3. Candidate adapterWalkable/path-clear world factsGait state
4. GaitPlant/swing state, SwingToIK knees or sprites
5. IK + hard resolveJoint pose, final legal simulation pointsNew gait policy
6. PresentationLift, shadow, sort, optional juiceSimulation state

Inside the gait stage

home = headingRelativeLocalHome(bodyPose)
stress = distance(plant, home)

if planted && stress > comfort && RetainsSupport(remainingPlants):
    candidates = adapter facts for this swing start
    swingTo = first/ranked legal candidate
    commit SwingTo and begin swing

if swinging && t >= 1:
    Plant = SwingTo
    commit planted state

Debug from cause to picture

  1. Draw desired velocity, body heading, local homes, and planar foot plants.
  2. Draw accepted/rejected candidates only at a swing transition.
  3. Draw support eligibility before showing IK or lift.
  4. Freeze presentation. If the creature slides now, find the last simulation writer.
  5. Only after the simulation is legal, tune lift/shadow/sorting.
