Second-Order Dynamics Cheatsheet

Universal juice filter (spring-damper with anticipation). Taught in Lesson 6; source: t3ssel8r, "Giving Personality to Procedural Animations using Math."

Constants (bake once, when f/ζ/r change)

ω  = 2π·f
k1 = ζ / (π·f)
k2 = 1 / ω²
k3 = r·ζ / ω

Update (per fixed step T)

xd  = (x - xPrev) / T          // input velocity estimate
xPrev = x
k2s = max(k2, T²/2 + T·k1/2, T·k1)          // stability clamp — never skip
y   = y + T·yd
yd  = yd + T·(x + k3·xd - y - k1·yd) / k2s
// y = juiced output; yd = velocity (free squash/lean driver)

The three knobs

KnobMeaningRange feel
f (Hz)Response speedLow = heavy/languid · High = snappy/twitchy
ζ (zeta)Damping / settle0 rings forever · <1 overshoots then settles · 1 critical (fastest, no overshoot) · >1 sluggish/stiff
rLaunch character<0 anticipates (backward wind-up) · 0 eases in · 1 immediate · >1 eager (overshoots to lead)

Term-by-term (the last line)

TermDoes
x − ySpring pulling output toward target
−k1·ydFriction — sets how it settles (ζ)
k3·xdFeeds target velocity into acceleration; negative k3 ⇒ anticipation

Gotchas

  • Fixed timestep only — k2s assumes a known T. Variable dt ⇒ inconsistent feel or instability.
  • Never skip the k2s clamp — high f at 60fps explodes without it.
  • Angles: wrap the error to [−π, π] before filtering, or it spins the long way.
  • ζ = 0 rings forever by design — not a bug, just rarely what you want.
  • Retune live: changing f/ζ/r means rebaking k1/k2/k3; the y/yd state carries over fine.

DOTS

  • State per value: float2 Y, Yd, Xp + float K1,K2,K3. Branchless update → one job juices millions.
  • Attach to any float/float2/quaternion: position, scale, lean, squash, camera, UI number, turret lead.
  • Per-instance (f,ζ,r) variation makes identical prefabs feel individual — highest juice-per-byte in the toolkit.
