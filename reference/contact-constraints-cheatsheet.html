Contact Constraints Cheatsheet

World contact for procedural chains, taught in Lesson 10.

The contract

Contact is a temporary, unilateral constraint. It pushes a penetrating point to the nearest legal position. It never attracts a point toward a wall or ground.

Circle or point against a surface

// n points out of the solid; signed distance d is positive outside
penetration = radius - d
if (penetration > 0) {
    p += n * penetration                 // project to legal position
    v  = p - prev
    vn = dot(v, n)
    vt = v - n * vn
    if (vn < 0) vn = 0                   // remove velocity into the surface
    prev = p - (n * vn + vt * (1-friction))
}

Order

Integrate → muscles → [distance constraints → contacts → joint limits] × sweeps → presentation. Interleave contacts with hard constraints: a contact correction changes link lengths; a link correction can reintroduce penetration.

Joint limit

Measure the signed 2D angle at a joint, clamp it to the authored interval, and rotate the child endpoint onto that boundary while preserving link length. A limit is also one-sided: it only acts outside the allowed interval.

Debug order

  1. Draw contact point, normal, and penetration depth.
  2. Disable friction: can the point cleanly project out?
  3. Interleave the contact constraint with length sweeps.
  4. Add joint limits after collision is independently legal.
