Conveyor Support Cheatsheet

Keeping a planted foot attached to material travelling through a moving support, taught in Lesson 13.

The contract

Support pose moves coordinates. Surface velocity moves material inside those coordinates. A conveyor plant is a support entity, a local landing point, and a local offset accumulated only while the foot remains planted.

// landing
leg.Support       = hit.Entity;
leg.LocalPlant    = InverseTransformPoint(hit.Entity, hit.Point);
leg.SurfaceOffset = 0;

// planted ticks
leg.SurfaceOffset += belt.VelocityLocal * dt;
localTarget        = leg.LocalPlant + leg.SurfaceOffset;
leg.WorldPlant     = pose.TransformPoint(localTarget);

// liftoff continuity
carryVelocity = pose.PointVelocity(localTarget)
              + pose.TransformDirection(belt.VelocityLocal);

Never confuse these

MotionState that represents it
Elevator / rotation / translationCurrent support pose applied to a local point.
Belt / treadmill / moving treadIntegrated surface offset in support-local coordinates.
New foothold decisionGait transition, queried and committed once—not an update to a planted foot.

Failure modes

ShortcutResult
Only transform the original local plantFoot rides the platform but not the belt material.
Only use belt world velocityBreaks when the support rotates; loses support-point velocity at liftoff.
Re-query while plantedTurns a stable material promise into sensor-following.
